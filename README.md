**Atlas Platinum Leonida — Peta Perjalanan 55 Trophy.** A guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies, drawn as a dark cartographer's atlas: the road to the platinum is a charted route through six stages, every trophy is a marker on that route, and the list's one missable trophy flies a red flag. The checklist shows each trophy's official name, description and grade exactly as PlayStation publishes them; progress is saved in the browser and can be exported to a file, imported back, or shared as a link; filters cover story, missable, collectibles, activities and online; a spoiler-safe setting hides story trophies until they are earned. Open any marker and its guide appears — written in the atlas's own words, with the source it draws on named beside it. Fully offline from its own files, and no Rockstar logo or artwork anywhere.

## Run it

```sh
python3 -m http.server 8080 --directory app
# open http://localhost:8080
```

Hand it in (Node 22, standard library only):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
