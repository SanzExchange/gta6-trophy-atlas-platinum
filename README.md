**Atlas Platinum Leonida — Peta Perjalanan 55 Trophy.** A journey-map guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies, drawn as a dark cartographer's atlas: the platinum roadmap is a charted route through six stages, every trophy is a marker on that route, and the one missable trophy flies a red flag. The checklist shows each trophy's official name, description and grade; progress is saved in the browser and can be exported, imported and shared as a link; filters cover story, missable, collectibles, activities and online; a spoiler setting hides story trophies until they are earned. Every trophy carries a guide written in the atlas's own words with its source named beside it. Works fully offline from its own files — no Rockstar logo or artwork anywhere.

## Run it

```sh
python3 -m http.server 8080 --directory app
# open http://localhost:8080
```

Hand it in (Node 22, standard library only):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
